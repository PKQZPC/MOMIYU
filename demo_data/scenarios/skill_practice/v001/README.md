# Skill practice v001

Six explicitly synthetic observations continue the existing egg-journey pet.
They do not replace or revise the original eleven growth records. Each of two
independent tasks has an observed starting state followed by actual simulated
process and result records. Prediction receives only the start; comparison
receives later steps after that prediction has been saved.

The actual execution uses only authorized stored observations and creates new
task files. It does not operate a real club, edit source files, perform outdoor
navigation, or claim that a human performed these synthetic observations.
Acquisition and proficiency remain model decisions backed by checks and actual
tool execution, never fixture assertions forced into the live profile.
