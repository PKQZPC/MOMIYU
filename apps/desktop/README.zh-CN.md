# 桌面使用指南

[English](README.md) · 简体中文 · [项目介绍](../../README.zh-CN.md)

当前 MOMIYU 在 Windows x64 上从源码运行。账号、宠物、经历、生成素材和任务结果均保存在项目目录。

## 启动

在仓库根目录，用已安装的 Python 3 执行：

```powershell
python tools/m0/prepare-electron.py
.\apps\desktop\open-demo.cmd
```

第一条命令下载并校验项目指定的 Electron 运行时，第二条打开本地账号入口。登录或注册后，选择并确认领取一颗蛋。领取后，这只宠物的蛋款式和颜色就确定了。

如果希望通过桌面图标或 **Ctrl+Alt+M** 启动，可以运行：

```powershell
.\tools\desktop\install-shortcut.ps1
```

快捷方式指向项目目录，请保留项目所在位置。正常启动只运行一个实例。

## 和它相处

| 操作 | 效果 |
| --- | --- |
| 鼠标悬停在宠物上 | 显示操作按钮，普通互动动作可以播放。 |
| 单击宠物 | 打开聊天。 |
| 双击宠物 | 查看成长详情。 |
| 拖动身体 | 移动桌宠。 |
| 点击「技能」 | 查看已习得技能、练习候选和任务成果。 |
| 点击「小睡／醒醒」 | 手动休息或叫醒它。 |
| 在设置中调整大小 | 改变桌宠显示尺寸并保存。 |
| 关闭面板 | 桌宠继续留在桌面。 |
| 点击桌宠旁的 × | 退出 MOMIYU。 |

成长手记记录历史形象和共同记忆。技能图鉴优先展示已学会的技能，卡片上可以查看能力介绍、熟练度，并填写下一次任务的目标。

## 配置模型

打开「相处设置」，可以选择两种连接方式。

| 方式 | 配置与验证情况 |
| --- | --- |
| 绑定 ChatGPT 账号 | 点击 **Continue with ChatGPT**，在浏览器中授权。绑定属于当前本地账号。分析、生图路由与用量记录已有模拟请求验证，直连方式的真实授权和生图仍待验证。 |
| 本地 API 代理 | 启动兼容代理，选择已有 YAML 配置。当前读取本机地址、端口和 API key。真实模型的经历分析、成长和本地技能执行已通过这条路径用模拟数据跑通。 |

开启模型调用，再选择允许使用的数据来源。「检查模型连接」用于验证已配置的接口。成长生图有单独的开关，一次成长可能需要设计图和动作素材，并经过多次分析。

绑定账号后，可以查看最近调用、累计已报告的 token 用量，以及更多历史。这里统计的是 MOMIYU 记录到的调用；服务方的余额和额度请在对应账号页面查看。

## 积累经历

采集和发送给模型分别控制。

| 当前来源 | 保存内容 |
| --- | --- |
| 电脑输入 | 分批记录 Windows 虚拟键码。当前记录的是按键事件，可靠读取现有输入法确认上屏的文本仍未解决。 |
| 定期截图 | 累计有效使用 30 分钟保存一张。阅读和看视频也计时，锁屏、待机和息屏时暂停。 |
| 宠物内聊天 | 根据聊天保存设置记录消息。 |
| 主动添加经历 | 保存你在面板中选择添加的内容。 |
| 选定文件 | 逐个选择的 UTF-8 txt、md、csv 文件的保存版本，单文件最多 32KB。 |

普通桌面入口通过按键事件和截图获取外部活动。旧的 Windows 界面读取适配器仍保留作实验用途，正常入口已停用。日常配置无需填写应用白名单或进行浏览器配对。

「一起经历」显示已保存记录，同时显示整理进度。「已整理」表示经历整理结果已保存，形象成长与技能准备可以在后续阶段分别完成。

## 小睡、整理和成长

默认开启自然打盹，并提供 **23:00–07:00** 的初始休息时段。时段以外，当前初始设置允许宠物在约 20 分钟没有直接互动或活跃任务后短暂打盹。正在聊天或执行任务时会延后，可以提前叫醒它。

跟随作息功能会观察账号运行期间较长的锁屏或待机间隔，积累足够的近期记录后，估计适合的休息时段。设置中会显示实际使用的时段和来源。可以关闭自动调整，手动指定时间；已有手动设置优先。

小睡可以单纯休息。存在新的可用经历或可续接阶段，且模型连接可用时，才会进行分析。成功整理过的原始记录会从后续经历整理批次中排除，整理出的记忆可以作为未来分析的背景。

AI 结合经历与历史形象判断成长。允许生图时，系统准备设计和可用动作，再让新形象生效。准备期间继续使用已有形象。外观和技能可以在不同轮小睡中成长。

## 学会并使用技能

做事方法先形成候选。后来的独立行为用于核对，预测会先保存，再揭示后续过程。实际试用和新证据会影响 AI 对习得与熟练度的判断。

习得评估和适配动作都准备好后，技能才会进入已获得列表。进入「技能」，填写本次目标并发动。任务进行时桌宠播放对应动作，结果保留在任务历史。

目前工具可以检索、读取已保存的经历，并创建新的本地任务文件。演示中的交接任务生成了带 Mermaid 流程图和问答的说明。联网检索和任意跨应用操作仍待开发。

[demo_data](../../demo_data/README.md) 提供模拟场景。准备好的测试账号需要本机保留相应档案和生成素材；克隆仓库会获得场景定义。

## 账号和本地文件

可以在账号入口注册或登录，选择在本机记住账号后，下次可点击继续使用。切换其他账号时使用对应凭据。退出登录会停止当前账号的采集，并返回账号入口。

普通账号和注册信息位于 `.local/desktop/`，已有演示档案沿用项目内原路径。数据库、凭据、缓存、临时文件和模型原始响应均保留在本地。

## 开发检查

桌面窗口与 IPC 在本目录，业务逻辑在 [local-runtime](../../services/local-runtime/README.md)，通用播放模块在 [pet-runtime](../../packages/pet-runtime/README.md)。

在仓库根目录运行隔离检查：

```powershell
.\tools\desktop\start.ps1 -Smoke
.\tools\desktop\start.ps1 -Smoke -VisibleCheck
```

可见检查会打开程序拥有的测试窗口。两种检查都使用模拟数据，不发起模型请求。原生交互检查工具位于 `tools/desktop/`。

本地开发版使用 `apps/desktop/package.json` 定义应用版本，准备发布时同步版本号、发布说明和 Git 标签。Electron 版本和模拟数据版本分别维护。
